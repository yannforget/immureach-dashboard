# Project Instructions

This is a React + TypeScript web application.

## Development

- Follow the existing project structure and patterns.
- Prefer existing components and utilities.
- Avoid adding dependencies unless necessary.
- Use TypeScript.
- Never use npm or curl. Don't try to deploy the app.

## Skills

When implementing or modifying frontend UI, use the `frontend-design` skill.
When creating, modifying, or debugging Playwright tests, use the `playwright-skill` skill.
